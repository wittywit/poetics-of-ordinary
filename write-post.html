    How to publish

    1. Fill in all fields above and click Publish Post.
    2. Two files download automatically: the post HTML and an updated index.html.
    3. Move both files into this website folder (replacing the existing index.html).
    4. Done. The new post appears in the homepage list immediately.
    5. Images uploaded via the + Image button are embedded as base64 — no separate image files needed.
